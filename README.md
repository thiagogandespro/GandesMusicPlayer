# GandesMusicPlayer
A basic music player for practice android basic concepts

This player was made based on the following references:
- https://developer.android.com/media/audio-and-video

About the project: 
My intention was to review and practice the fundamentals components of android development, 
such as activities, services, broadcast receivers, and content providers as presented
in the official documentation. [https://developer.android.com/guide/components/fundamentals]
